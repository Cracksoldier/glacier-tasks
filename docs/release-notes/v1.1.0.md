## Glacier Tasks 1.1.0

Glacier Tasks can now keep running in the system tray.

### New

- **System tray:** under **Settings → Window** you can choose that closing the window keeps the
  app running in the system tray, and that minimizing hides the window there. Both options are
  off unless you turn them on.
  - The tray icon only appears while one of the options is on. Its menu opens or quits the app;
    on Windows, a click on the icon opens the window.
  - The first time the window goes to the tray, a notification tells you that the app is still
    running.
  - Starting Glacier Tasks again also brings the window back. This helps on Linux desktops that
    don't show tray icons (for example GNOME without the AppIndicator extension).

### Installation

| File | System |
| --- | --- |
| `Glacier-Tasks-1.1.0-win-x64-Setup.exe` | Windows 10/11, x64 |
| `Glacier-Tasks-1.1.0-linux-x86_64.AppImage` | Linux x64 (needs `libfuse2` on some distributions) |
| `Glacier-Tasks-1.1.0-linux-amd64.deb` | Debian/Ubuntu x64 |

The builds are **not code-signed**. Check your download against `SHA256SUMS.txt`; on Windows,
SmartScreen may ask for confirmation. Your data, backups and settings from 1.0.x keep working
without changes.

## Glacier Tasks 1.1.0 (Deutsch)

Glacier Tasks kann jetzt im Infobereich weiterlaufen.

### Neu

- **Infobereich:** unter **Einstellungen → Fenster** kannst du festlegen, dass die App beim
  Schließen des Fensters im Infobereich weiterläuft und das Fenster beim Minimieren dorthin
  verschwindet. Beide Optionen sind aus, bis du sie einschaltest.
  - Das Symbol im Infobereich erscheint nur, solange eine der Optionen an ist. Sein Menü öffnet
    oder beendet die App; unter Windows öffnet ein Klick auf das Symbol das Fenster.
  - Wenn das Fenster zum ersten Mal in den Infobereich geht, weist eine Benachrichtigung darauf
    hin, dass die App weiterläuft.
  - Ein erneuter Start von Glacier Tasks holt das Fenster ebenfalls zurück. Das hilft auf
    Linux-Desktops, die keine Symbole im Infobereich anzeigen (zum Beispiel GNOME ohne die
    AppIndicator-Erweiterung).

### Installation

| Datei | System |
| --- | --- |
| `Glacier-Tasks-1.1.0-win-x64-Setup.exe` | Windows 10/11, x64 |
| `Glacier-Tasks-1.1.0-linux-x86_64.AppImage` | Linux x64 (braucht auf manchen Distributionen `libfuse2`) |
| `Glacier-Tasks-1.1.0-linux-amd64.deb` | Debian/Ubuntu x64 |

Die Builds sind **nicht signiert**. Prüfe deinen Download mit `SHA256SUMS.txt`; unter Windows
fragt SmartScreen eventuell nach. Deine Daten, Backups und Einstellungen aus 1.0.x funktionieren
ohne Änderungen weiter.
