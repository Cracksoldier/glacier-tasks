## Glacier Tasks 1.0.3

Stories can now be exported and imported, and long histories are easier to read.

### New

- **Export and import a story:** **Export** on a story saves it with its subtasks as a
  `.story.json` file. **Import story** on a project page reads such a file into that project,
  in the same or another installation.
  - The story and its subtasks get new IDs. Their history starts with the import and notes
    where they came from.
  - Statuses are matched by name. If the project has no status of the same name, you choose
    where those tasks go before importing.
  - You choose one assignee for the story and all subtasks, or leave them unassigned.
  - Labels with the same name are reused; missing ones are created with their colour.
  - Attachments are not part of the file. The import tells you when a description refers to
    attachments.
- **Shorter histories:** task and profile history show the newest 10 entries. **Show all**
  expands the list and **Show less** collapses it again. The project's Activity tab keeps its
  paging.

### Installation

| File | System |
| --- | --- |
| `Glacier-Tasks-1.0.3-win-x64-Setup.exe` | Windows 10/11, x64 |
| `Glacier-Tasks-1.0.3-linux-x86_64.AppImage` | Linux x64 (needs `libfuse2` on some distributions) |
| `Glacier-Tasks-1.0.3-linux-amd64.deb` | Debian/Ubuntu x64 |

The builds are **not code-signed**. Check your download against `SHA256SUMS.txt`; on Windows,
SmartScreen may ask for confirmation. Your data and backups from 1.0.x keep working without
changes.

## Glacier Tasks 1.0.3 (Deutsch)

Stories lassen sich jetzt exportieren und importieren, und lange Verläufe sind übersichtlicher.

### Neu

- **Story exportieren und importieren:** **Exportieren** auf einer Story speichert sie mit
  ihren Unteraufgaben als `.story.json`-Datei. **Story importieren** auf einer Projektseite
  liest eine solche Datei in dieses Projekt ein, in derselben oder einer anderen Installation.
  - Die Story und ihre Unteraufgaben erhalten neue IDs. Ihr Verlauf beginnt mit dem Import und
    zeigt, woher sie stammen.
  - Status werden über den Namen zugeordnet. Hat das Projekt keinen Status mit gleichem Namen,
    wählst du vor dem Import, wohin diese Aufgaben kommen.
  - Du wählst eine zuständige Person für die Story und alle Unteraufgaben, oder lässt sie
    unzugewiesen.
  - Labels mit gleichem Namen werden wiederverwendet, fehlende mit ihrer Farbe angelegt.
  - Anhänge sind nicht Teil der Datei. Der Import weist darauf hin, wenn eine Beschreibung auf
    Anhänge verweist.
- **Kürzere Verläufe:** der Verlauf von Aufgaben und Profilen zeigt die neuesten 10 Einträge.
  **Alle anzeigen** klappt die Liste auf, **Weniger anzeigen** wieder zu. Der Aktivität-Tab des
  Projekts blättert weiterhin seitenweise.

### Installation

| Datei | System |
| --- | --- |
| `Glacier-Tasks-1.0.3-win-x64-Setup.exe` | Windows 10/11, x64 |
| `Glacier-Tasks-1.0.3-linux-x86_64.AppImage` | Linux x64 (braucht auf manchen Distributionen `libfuse2`) |
| `Glacier-Tasks-1.0.3-linux-amd64.deb` | Debian/Ubuntu x64 |

Die Builds sind **nicht signiert**. Prüfe deinen Download mit `SHA256SUMS.txt`; unter Windows
fragt SmartScreen eventuell nach. Deine Daten und Backups aus 1.0.x funktionieren ohne
Änderungen weiter.
