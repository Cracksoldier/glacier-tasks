## Glacier Tasks 1.0.2

A bug-fix release for the board grouped by subtasks.

### Fixed

- **Reordering in swimlanes:** with **Group: Subtasks**, a card moved to another place in its
  column snapped back to where it was. Subtasks and the stories under **Other stories** can now
  be reordered within a column, and the order is kept.
- **Drop position:** a subtask dragged into another status now stays where you drop it instead
  of jumping to its old place in the order. Stories under **Other stories** still go to the top
  of a new column, as on the normal board.

### Installation

| File | System |
| --- | --- |
| `Glacier-Tasks-1.0.2-win-x64-Setup.exe` | Windows 10/11, x64 |
| `Glacier-Tasks-1.0.2-linux-x86_64.AppImage` | Linux x64 (needs `libfuse2` on some distributions) |
| `Glacier-Tasks-1.0.2-linux-amd64.deb` | Debian/Ubuntu x64 |

The builds are **not code-signed**. Check your download against `SHA256SUMS.txt`; on Windows,
SmartScreen may ask for confirmation. Your data and backups from 1.0.x keep working without
changes.

## Glacier Tasks 1.0.2 (Deutsch)

Eine Fehlerbehebung für das nach Unteraufgaben gruppierte Board.

### Behoben

- **Sortieren in Swimlanes:** mit **Gruppieren: Unteraufgaben** sprang eine Karte, die an eine
  andere Stelle ihrer Spalte gezogen wurde, an ihren alten Platz zurück. Unteraufgaben und die
  Stories unter **Weitere Stories** lassen sich jetzt innerhalb einer Spalte umsortieren, und
  die Reihenfolge bleibt erhalten.
- **Ablageposition:** eine Unteraufgabe, die in einen anderen Status gezogen wird, bleibt jetzt
  dort, wo du sie ablegst, statt an ihren alten Platz in der Reihenfolge zu springen. Stories
  unter **Weitere Stories** kommen in einer neuen Spalte weiterhin nach oben, wie auf dem
  normalen Board.

### Installation

| Datei | System |
| --- | --- |
| `Glacier-Tasks-1.0.2-win-x64-Setup.exe` | Windows 10/11, x64 |
| `Glacier-Tasks-1.0.2-linux-x86_64.AppImage` | Linux x64 (braucht auf manchen Distributionen `libfuse2`) |
| `Glacier-Tasks-1.0.2-linux-amd64.deb` | Debian/Ubuntu x64 |

Die Builds sind **nicht signiert**. Prüfe deinen Download mit `SHA256SUMS.txt`; unter Windows
fragt SmartScreen eventuell nach. Deine Daten und Backups aus 1.0.x funktionieren ohne
Änderungen weiter.
